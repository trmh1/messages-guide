# Three Rivers Messages Handbook

How the Messages page in the Three Rivers Mental Health dashboard works, for front desk, Billing,
providers and admins. Served by GitHub Pages at https://trmh1.github.io/messages-guide/ (marked
noindex). Every screenshot uses invented test data, never a real patient.

`index.html` is generated. Don't edit it here: change the chapters in the dashboard repository
(`docs/messages-handbook/`), rebuild with `build/build.py --standalone`, and replace this file.
